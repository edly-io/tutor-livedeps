- 💥[Bugfix] Support Granian, which replaced uWSGI in Tutor. The LMS and CMS containers now start with `livedeps serve`, which downloads the dependencies, checks for new ones every minute, reloads the workers with `reload-granian` when they change, and runs Granian. The `uwsgi-config` patch is removed. (by @Faraz32123)
- [Improvement] Swap in new dependencies only once they are fully downloaded, so a failed download no longer deletes the current ones. (by @Faraz32123)
